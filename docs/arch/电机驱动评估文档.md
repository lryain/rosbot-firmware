# 电机驱动芯片评估报告：DRV8848 vs MAX22205 vs DRV8874

> 本文档评估三款电机驱动芯片的兼容性，分析 ROSbot PRO 使用 DRV8874 替代的可行性。

---

## 1. 芯片概述

### 1.1 DRV8848 — ROSbot 原始方案

| 参数 | 值 |
|------|------|
| 厂商 | Texas Instruments |
| 封装 | TSSOP-16 |
| 通道数 | **2 通道**（双 H 桥） |
| 峰值电流 | 2A/通道 |
| RMS 电流 | 1A/通道 |
| 电源电压 | 2V ~ 18V |
| 控制接口 | IN1/IN2 + nSLEEP + nFAULT（每通道） |
| PWM 频率 | 最高 250kHz |
| 保护 | 过流、过温、欠压锁定 |
| 逻辑电平 | 1.8V ~ 5V 兼容 |

**ROSbot 连接方式**（每个芯片驱动 2 个电机）：
- 每通道 3 线：`pwm_pin`（实际接 EN/PWM）、`in_a_pin`、`in_b_pin`
- 共享信号：`nSLEEP`（使能）、`nFAULT`（故障检测）
- 2 个芯片驱动 4 个电机

### 1.2 MAX22205 — ROSbot XL 方案

| 参数 | 值 |
|------|------|
| 厂商 | Analog Devices (Maxim) |
| 封装 | TQFN-24 |
| 通道数 | **1 通道**（单 H 桥） |
| 峰值电流 | 5A |
| RMS 电流 | 3.5A |
| 电源电压 | 4.5V ~ 36V |
| 控制接口 | IN1/IN2 + EN + ILIM + nFAULT |
| PWM 频率 | 最高 100kHz |
| 保护 | 过流、过温、欠压锁定、ILIM 可调 |
| 逻辑电平 | 1.8V ~ 5.5V 兼容 |

**ROSbot XL 连接方式**（每个芯片驱动 1 个电机）：
- 每通道 3 线：`pwm_pin`（EN/PWM）、`in_a_pin`（IN1）、`in_b_pin`（IN2）
- ILIM 引脚：4 路独立电流限制（PE10, PG15, PG7, PD14）
- 共享信号：`nSLEEP` 和 `nFAULT` 按左右组分组
- 4 个芯片驱动 4 个电机

### 1.3 DRV8874 — ROSbot PRO 候选方案

| 参数 | 值 |
|------|------|
| 厂商 | Texas Instruments |
| 封装 | HTSSOP-16 |
| 通道数 | **1 通道**（单 H 桥） |
| 峰值电流 | 6A |
| RMS 电流 | 3.5A (37V) |
| 电源电压 | 4.5V ~ 37V |
| 控制接口 | **双模式** — PH/EN 或 IN/IN |
| PWM 频率 | 最高 100kHz |
| 保护 | 过流、过温、欠压锁定、IPROPI 电流回报 |
| 逻辑电平 | 1.8V ~ 5V 兼容 |
| 特色 | 电流回报引脚（IPROPI）、PMODE 模式选择 |

## 2. 控制模式对比

### 2.1 DRV8848 / MAX22205 — Hi-Z 控制模式

这是 ROSbot 固件当前使用的控制方式，代码位于 `motor_drv8848.cpp`：

```
┌──────────┬──────────┬──────────┬──────────────────────────┐
│   模式   │   IN_A   │   IN_B   │       PWM (EN)            │
├──────────┼──────────┼──────────┼──────────────────────────┤
│ FORWARD  │  Hi-Z    │  LOW     │  占空比控制速度            │
│ REVERSE  │  LOW     │  Hi-Z    │  占空比控制速度            │
│ BRAKE    │  HIGH    │  HIGH    │  全占空比                  │
│ NEUTRAL  │  LOW     │  LOW     │  零占空比                  │
└──────────┴──────────┴──────────┴──────────────────────────┘
```

**关键代码**（`motor_drv8848.cpp`）：
```cpp
case MotorMode::FORWARD:
    pinMode(pin_a, INPUT);   // Hi-Z → 浮空
    pinMode(pin_b, OUTPUT);
    digitalWrite(pin_b, LOW);
    break;

case MotorMode::REVERSE:
    pinMode(pin_a, OUTPUT);
    digitalWrite(pin_a, LOW);
    pinMode(pin_b, INPUT);   // Hi-Z → 浮空
    break;
```

这种模式的核心特征是：
- PWM 信号施加在 EN/nSLEEP 引脚上
- IN_A 和 IN_B 通过 Hi-Z（设为 INPUT 浮空）与 LOW 的组合控制方向
- 当 IN 引脚为 Hi-Z 时，该引脚对应的半桥"跟随" PWM 信号

### 2.2 DRV8874 — 双模式

DRV8874 通过 **PMODE** 引脚选择控制模式：

#### 模式 1：PH/EN 模式（PMODE = GND）

```
┌──────────┬──────────┬──────────┬──────────────────────────┐
│   模式   │  PH(IN1) │  EN(IN2) │       效果               │
├──────────┼──────────┼──────────┼──────────────────────────┤
│ FORWARD  │  LOW     │  PWM     │  OUT1=PWM, OUT2=GND      │
│ REVERSE  │  HIGH    │  PWM     │  OUT1=GND, OUT2=PWM      │
│ BRAKE    │    X     │  LOW     │  两路输出接低              │
│ COAST    │    X     │  nSLEEP=LOW │  Hi-Z                 │
└──────────┴──────────┴──────────┴──────────────────────────┘
```

#### 模式 2：IN/IN 模式（PMODE = VCC 或浮空）

```
┌──────────┬──────────┬──────────┬──────────────────────────┐
│   模式   │   IN1    │   IN2    │       效果               │
├──────────┼──────────┼──────────┼──────────────────────────┤
│ FORWARD  │  PWM     │  LOW     │  OUT1=PWM, OUT2=LOW      │
│ REVERSE  │  LOW     │  PWM     │  OUT1=LOW, OUT2=PWM      │
│ BRAKE    │  LOW     │  LOW     │  低端制动                 │
│ BRAKE    │  HIGH    │  HIGH    │  高端制动                 │
│ COAST    │  nSLEEP=LOW │      │  Hi-Z                    │
└──────────┴──────────┴──────────┴──────────────────────────┘
```

## 3. 兼容性分析

### 3.1 为什么 DRV8848 和 MAX22205 代码兼容？

ROSbot XL 使用 MAX22205 但仍使用 `motor_drv8848.hpp` 代码，原因是：

1. **相同的控制逻辑**：两者都支持 IN1/IN2 + EN 的控制模式
2. **Hi-Z 行为兼容**：在 IN 引脚设为 Hi-Z（高阻态）时，两者行为一致：
   - DRV8848：IN 浮空时，对应半桥跟随 nSLEEP/EN 的 PWM
   - MAX22205：IN 浮空时，内部上拉/默认状态使对应半桥跟随 EN 的 PWM
3. **引脚数量一致**：每通道都是 3 线控制（PWM + IN_A + IN_B）
4. **nSLEEP/nFAULT 共享通道完全兼容**

**关键发现**：`motor_drv8848.cpp` 中的代码注释 `// TODO: Can be improved and used tourque control` 暗示 MAX22205 的 ILIM（电流限制/力矩控制）功能尚未完全利用。

### 3.2 DRV8874 兼容性评估

#### ❌ PH/EN 模式 — **不兼容**

PH/EN 模式使用完全不同的控制逻辑：
- PH 控制方向（HIGH/LOW），EN 控制 PWM
- 无法通过 Hi-Z 来控制方向
- 需要重写 `setMode()` 和 `applyPWM()` 函数

#### ✅ IN/IN 模式 — **部分兼容，需要适配**

IN/IN 模式更接近现有控制逻辑，但仍有重要区别：

| 特性 | 现有代码 (DRV8848) | DRV8874 IN/IN | 兼容？ |
|------|-------------------|---------------|--------|
| PWM 施加位置 | EN/nSLEEP 引脚 | IN1 或 IN2 引脚 | ❌ 不同 |
| 方向控制 | Hi-Z + LOW 组合 | PWM + LOW 组合 | ⚠️ 不同机制 |
| 制动 | IN_A=HIGH, IN_B=HIGH | IN1=LOW, IN2=LOW 或都高 | ⚠️ 逻辑不同 |
| 空转 | IN_A=LOW, IN_B=LOW | nSLEEP=LOW | ⚠️ 需要额外引脚 |

**核心差异**：DRV8874 IN/IN 模式中，PWM 信号直接施加在 IN1 或 IN2 引脚上，而不是独立的 EN 引脚。这意味着：

1. **不需要单独的 PWM 引脚**：PWM 直接通过 IN 引脚施加
2. **方向切换方式不同**：不使用 Hi-Z，而是一路 PWM + 另一路 LOW
3. **需要两路 PWM 通道**：FORWARD 时 IN1=PWM/IN2=LOW，REVERSE 时 IN1=LOW/IN2=PWM

### 3.3 兼容性结论

```
DRV8848  ←──完全兼容──→ MAX22205
    │                      │
    │    Hi-Z 控制方案     │
    │    PWM 在 EN 引脚    │
    ▼                      ▼
DRV8874 ←──需要新驱动──→ 不直接兼容
    │
    ├── PH/EN 模式：完全不兼容，需全新驱动
    │
    └── IN/IN 模式：概念相似但实现不同，需适配
```

## 4. DRV8874 实施方案推荐

### 4.1 推荐：IN/IN 模式 + 新驱动类

建议创建新的 `MotorDrv8874` 驱动类，实现 `MotorInterface`：

**每个电机需要的引脚**：
| 引脚 | 功能 | 说明 |
|------|------|------|
| IN1 | PWM/方向 | 需要定时器 PWM 通道 |
| IN2 | PWM/方向 | 需要定时器 PWM 通道 |
| nSLEEP | 使能 | 高电平使能，可多路共享 |
| nFAULT | 故障 | 低电平故障，可多路共享 |
| IPROPI | 电流回报 | ADC 输入（可选） |

**引脚需求变化**：

| 方案 | PWM引脚/电机 | GPIO引脚/电机 | 总引脚/电机 |
|------|-------------|-------------|------------|
| DRV8848 | 1 (EN) | 2 (IN_A, IN_B) | 3 + 共享 nSLEEP/nFAULT |
| MAX22205 | 1 (EN) | 2 (IN1, IN2) + 1 (ILIM) | 4 + 共享 nSLEEP/nFAULT |
| DRV8874 IN/IN | 2 (IN1, IN2) | 0 | 2 + 共享 nSLEEP/nFAULT + 可选 IPROPI |

**关键变化**：DRV8874 每个电机需要 **2 路 PWM** 但不需要额外 GPIO。

### 4.2 定时器资源评估

STM32F407LGT6 (LQFP-144) 拥有丰富的定时器资源：
- TIM1-TIM14 共 14 个定时器
- 4 路编码器占用 TIM1/TIM2/TIM3/TIM4
- 风扇 PWM 占用 TIM8 CH2N
- 运行时统计占用 TIM5

剩余可用于电机 PWM 的定时器：TIM9/TIM10/TIM11/TIM12/TIM13/TIM14 以及 TIM6/TIM7（基本定时器，无 PWM）

**4 个电机 × 2 路 PWM = 8 路 PWM 通道**

可行方案：
- TIM9: 2 通道 (CH1, CH2)
- TIM10: 1 通道
- TIM11: 1 通道
- TIM12: 2 通道 (CH1, CH2)
- TIM13: 1 通道
- TIM14: 1 通道

**或者用同定时器不同通道**：某些定时器有 4 通道（TIM1-TIM5、TIM8），但已被占用。需要在引脚分配时仔细规划。

### 4.3 DRV8874 的额外优势

| 特性 | 说明 | 价值 |
|------|------|------|
| IPROPI | 电流回报引脚，输出与负载成比例的电流 | 可实现力矩控制、堵转检测 |
| PMODE | 硬件选择 PH/EN 或 IN/IN | 灵活适配 |
| 37V max | 比 DRV8848(18V) 和 MAX22205(36V) 更高 | 更大电压裕量 |
| 6A peak | 最高峰值电流 | 更强驱动力 |
| HTSSOP-16 | 散热焊盘 | 更好的热管理 |

### 4.4 替代方案：PH/EN 模式

如果选择 PH/EN 模式，每个电机只需 **1 路 PWM + 1 路 GPIO**，引脚需求与现有方案一致：

| 引脚 | 功能 |
|------|------|
| EN (PWM) | 速度控制，一路 PWM |
| PH (GPIO) | 方向控制，HIGH=正转，LOW=反转 |

PH/EN 模式更简洁，但丧失了 Hi-Z 刹车等高级功能。

## 5. 综合推荐

| 维度 | PH/EN 模式 | IN/IN 模式 |
|------|-----------|-----------|
| PWM 通道需求 | 4 路（与现有相同） | 8 路（需求翻倍） |
| GPIO 需求 | 4 路（方向） | 0 路（方向由 PWM 控制） |
| 代码改动量 | 中等 | 中等 |
| 控制精度 | 好 | 更好（独立半桥控制） |
| 刹车模式 | 被动制动 | 主动高低端制动 |
| 推荐度 | ⭐⭐⭐ | ⭐⭐⭐⭐ |

**最终推荐：IN/IN 模式**

理由：
1. 更精确的电机控制
2. 支持独立半桥 PWM，可实现更好的再生制动
3. 虽然需要更多 PWM 通道，但 STM32F407 定时器资源充足
4. 与 DRV8874 的设计初衷更匹配
