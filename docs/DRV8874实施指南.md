# DRV8874 电机驱动实施指南

> 本文档详细说明如何在 ROSbot PRO 固件中实现 DRV8874 电机驱动支持，包括硬件连接、驱动代码、引脚分配和测试方法。

---

## 1. DRV8874 硬件设计

### 1.1 芯片引脚功能（HTSSOP-16）

| 引脚号 | 名称 | 功能 | 连接说明 |
|--------|------|------|---------|
| 1 | nSLEEP | 低功耗模式控制 | 高电平使能，可接 MCU GPIO（共享） |
| 2 | VREF | 参考电压输入 | 接 VCC (3.3V) |
| 3 | IN1 | 输入1 / PH | 接 MCU PWM 输出 |
| 4 | IN2 | 输入2 / EN | 接 MCU PWM 输出 |
| 5 | PMODE | 模式选择 | 接 VCC=IN/IN 模式, 接 GND=PH/EN 模式 |
| 6 | nFAULT | 故障输出 | 开漏低电平有效，接 MCU GPIO（共享），需上拉 |
| 7 | IPROPI | 电流回报 | 接 ADC 输入（可选），通过外部电阻设置比例 |
| 8 | EN/IN2 | 使能/输入2 | 同引脚4，参见模式选择 |
| 9-12 | OUT1/OUT2 | 功率输出 | 接电机 |
| 13 | VM | 电机电源 | 接电池电压（4.5V ~ 37V） |
| 14 | PGND | 功率地 | 接电源地，需要良好的PCB布局 |
| 15 | AGND | 模拟地 | 接信号地 |
| 16 | CPL/CPH | 电荷泵 | 外接 47nF 电容 |
| PAD | 散热焊盘 | 焊接到 PCB 铜皮 | 大面积铺铜 |

### 1.2 推荐外围电路（IN/IN 模式）

```
                 ┌────────────────────────┐
    VCC 3.3V ───▶│ VREF                   │
                 │                        │
    MCU PWM1 ──▶│ IN1          OUT1 ─────├──▶ 电机 M+
    MCU PWM2 ──▶│ IN2          OUT2 ─────├──▶ 电机 M-
                 │                        │
    VCC 3.3V ──▶│ PMODE (IN/IN mode)     │
                 │                        │
    MCU GPIO ──▶│ nSLEEP                 │ ← 共享 2 个一组
    MCU GPIO ◀──│ nFAULT (开漏)           │ ← 共享 2 个一组
                 │                        │
                 │ IPROPI ──┬── RIPROPI ──├── GND
                 │          │             │
                 │          └── MCU ADC   │ (可选)
                 │                        │
    VBAT ───────▶│ VM                     │
                 │ CPL ──┤47nF├── CPH     │
                 │ PGND ─────────── GND   │
                 │ AGND ─────────── GND   │
                 └────────────────────────┘

去耦电容：VM 引脚旁放置 0.1µF + 10µF 陶瓷电容
电荷泵电容：CPL-CPH 之间 47nF 陶瓷电容
IPROPI 电阻：RIPROPI = VREF / (IPROPI_RATIO × I_FULL_SCALE)
    典型值：1kΩ（约 3.3A 满量程 @ 3.3V VREF）
```

### 1.3 驱动组分组

ROSbot PRO 使用 4 个 DRV8874，按左右侧分组：

```
右侧驱动组 (nSLEEP 共享, nFAULT 共享):
  ├── DRV8874 #1 → FR (前右电机)
  └── DRV8874 #2 → RR (后右电机)

左侧驱动组 (nSLEEP 共享, nFAULT 共享):
  ├── DRV8874 #3 → FL (前左电机)
  └── DRV8874 #4 → RL (后左电机)
```

## 2. 驱动代码实现

### 2.1 配置结构体

```cpp
// motor_drv8874.hpp

struct MotorDrv8874Config {
  uint8_t in1_pin;       // IN1 — PWM 输出引脚
  uint8_t in2_pin;       // IN2 — PWM 输出引脚
  bool inv_dir;          // 方向取反
  float max_velocity;    // [rad/s] 速度上限
  float min_velocity;    // [rad/s] 死区
  uint32_t pwm_freq;     // [Hz] PWM 频率 (推荐 20kHz)
  const char* frame_id;  // ROS joint 名称
};
```

对比现有 DRV8848 配置：
```cpp
// motor_drv8848.hpp — 对比
struct MotorDrv8848Config {
  uint8_t pwm_pin;     // PWM output (EN pin)
  uint8_t in_a_pin;    // direction input A — GPIO
  uint8_t in_b_pin;    // direction input B — GPIO
  // ...
};
```

**关键区别**：DRV8874 的 IN1/IN2 都是 PWM 引脚，取消了独立的 EN PWM 引脚。

### 2.2 驱动类实现

```cpp
// motor_drv8874.hpp

#pragma once
#include <Arduino.h>
#include <HardwareTimer.h>
#include <atomic>
#include "encoder_interface.hpp"
#include "motor_interface.hpp"
#include "pid.hpp"

enum MotorMode8874 : uint8_t { FORWARD, REVERSE, BRAKE, COAST };

struct MotorDrv8874Config {
  uint8_t in1_pin;       // PWM channel 1
  uint8_t in2_pin;       // PWM channel 2
  bool inv_dir;
  float max_velocity;
  float min_velocity;
  uint32_t pwm_freq;
  const char* frame_id;
};

class MotorDrv8874 : public MotorInterface {
 public:
  MotorDrv8874() = default;
  explicit MotorDrv8874(const MotorDrv8874Config& cfg,
                        EncoderInterface* encoder, PIDController pid)
      : cfg_(cfg), encoder_(encoder), pid_(pid) {}

  void init() override;
  void update(float dt, bool move = true) override;
  void reset() override;
  void setVelocity(float vel) override;
  void brake() override;
  void setNeutral() override;
  void setEnabled(bool en) override { enabled_ = en; }
  MotorData getData() const override;
  const char* name() const override { return cfg_.frame_id; }

 private:
  void setMode(MotorMode8874 mode);
  void applyPWM(float duty);

  MotorDrv8874Config cfg_ = {};
  EncoderInterface* encoder_ = nullptr;
  PIDController pid_;

  // 双通道 PWM — 同一或不同定时器
  HardwareTimer* pwm_timer_1_ = nullptr;
  HardwareTimer* pwm_timer_2_ = nullptr;
  uint32_t pwm_channel_1_ = 0;
  uint32_t pwm_channel_2_ = 0;
  uint16_t pwm_arr_ = 0;

  std::atomic<float> target_velocity_{0.0f};
  std::atomic<float> current_effort_{0.0f};
  MotorMode8874 current_mode_ = MotorMode8874::COAST;
  bool enabled_ = false;
};
```

### 2.3 控制逻辑实现

```cpp
// motor_drv8874.cpp

#include "motor_drv8874.hpp"

void MotorDrv8874::init() {
  // 初始化 IN1 PWM
  PinName in1_pn = digitalPinToPinName(cfg_.in1_pin);
  TIM_TypeDef* tim1 = (TIM_TypeDef*)pinmap_peripheral(in1_pn, PinMap_PWM);
  pwm_channel_1_ = STM_PIN_CHANNEL(pinmap_function(in1_pn, PinMap_PWM));
  pwm_timer_1_ = new HardwareTimer(tim1);
  pwm_timer_1_->setPWM(pwm_channel_1_, in1_pn, cfg_.pwm_freq, 0);

  // 初始化 IN2 PWM
  PinName in2_pn = digitalPinToPinName(cfg_.in2_pin);
  TIM_TypeDef* tim2 = (TIM_TypeDef*)pinmap_peripheral(in2_pn, PinMap_PWM);
  pwm_channel_2_ = STM_PIN_CHANNEL(pinmap_function(in2_pn, PinMap_PWM));

  // 如果是同一个定时器，共享实例
  if (tim1 == tim2) {
    pwm_timer_2_ = pwm_timer_1_;
  } else {
    pwm_timer_2_ = new HardwareTimer(tim2);
  }
  pwm_timer_2_->setPWM(pwm_channel_2_, in2_pn, cfg_.pwm_freq, 0);

  // 两个通道使用相同的 ARR
  pwm_arr_ = pwm_timer_1_->getOverflow(TICK_FORMAT);

  setMode(MotorMode8874::COAST);
}

void MotorDrv8874::setMode(MotorMode8874 mode) {
  if (mode == current_mode_) return;
  current_mode_ = mode;

  // 根据 inv_dir 决定实际通道映射
  HardwareTimer* t_fwd = cfg_.inv_dir ? pwm_timer_2_ : pwm_timer_1_;
  uint32_t ch_fwd = cfg_.inv_dir ? pwm_channel_2_ : pwm_channel_1_;
  HardwareTimer* t_rev = cfg_.inv_dir ? pwm_timer_1_ : pwm_timer_2_;
  uint32_t ch_rev = cfg_.inv_dir ? pwm_channel_1_ : pwm_channel_2_;

  switch (mode) {
    case MotorMode8874::FORWARD:
      // IN1=PWM, IN2=LOW
      t_rev->setCaptureCompare(ch_rev, 0);  // IN2 = 0%
      break;

    case MotorMode8874::REVERSE:
      // IN1=LOW, IN2=PWM
      t_fwd->setCaptureCompare(ch_fwd, 0);  // IN1 = 0%
      break;

    case MotorMode8874::BRAKE:
      // IN1=LOW, IN2=LOW → 低端制动
      pwm_timer_1_->setCaptureCompare(pwm_channel_1_, 0);
      pwm_timer_2_->setCaptureCompare(pwm_channel_2_, 0);
      break;

    case MotorMode8874::COAST:
    default:
      // 通过 nSLEEP=LOW 实现，这里只清零 PWM
      pwm_timer_1_->setCaptureCompare(pwm_channel_1_, 0);
      pwm_timer_2_->setCaptureCompare(pwm_channel_2_, 0);
      break;
  }
}

void MotorDrv8874::applyPWM(float duty) {
  duty = constrain(duty, -1.0f, 1.0f);
  current_effort_.store(duty, std::memory_order_relaxed);

  if (fabs(duty) < 0.01f) {
    setMode(MotorMode8874::BRAKE);
    return;
  }

  uint16_t pwm_value = static_cast<uint16_t>(fabs(duty) * pwm_arr_);

  if (duty > 0) {
    setMode(MotorMode8874::FORWARD);
    HardwareTimer* t = cfg_.inv_dir ? pwm_timer_2_ : pwm_timer_1_;
    uint32_t ch = cfg_.inv_dir ? pwm_channel_2_ : pwm_channel_1_;
    t->setCaptureCompare(ch, pwm_value);
  } else {
    setMode(MotorMode8874::REVERSE);
    HardwareTimer* t = cfg_.inv_dir ? pwm_timer_1_ : pwm_timer_2_;
    uint32_t ch = cfg_.inv_dir ? pwm_channel_1_ : pwm_channel_2_;
    t->setCaptureCompare(ch, pwm_value);
  }
}

// 以下函数与 DRV8848 实现完全一致
void MotorDrv8874::setVelocity(float vel) {
  float v = constrain(vel, -cfg_.max_velocity, cfg_.max_velocity);
  if (fabs(v) < cfg_.min_velocity) v = 0.0f;
  target_velocity_.store(v, std::memory_order_relaxed);
}

void MotorDrv8874::setNeutral() {
  target_velocity_.store(0.0f, std::memory_order_relaxed);
  setMode(MotorMode8874::COAST);
  pid_.reset();
}

void MotorDrv8874::brake() {
  target_velocity_.store(0.0f, std::memory_order_relaxed);
  current_effort_.store(0.0f, std::memory_order_relaxed);
  setMode(MotorMode8874::BRAKE);
  pid_.reset();
}

void MotorDrv8874::update(float dt, bool move) {
  if (!move) { brake(); return; }

  const float target = target_velocity_.load(std::memory_order_relaxed);
  const float current = encoder_ ? encoder_->getData().velocity : 0.0f;
  const float output = pid_.compute(target, current, dt);
  applyPWM(output);
}

void MotorDrv8874::reset() {
  brake();
  target_velocity_.store(0.0f, std::memory_order_relaxed);
  current_effort_.store(0.0f, std::memory_order_relaxed);
  pid_.reset();
  if (encoder_) encoder_->reset();
}

MotorData MotorDrv8874::getData() const {
  MotorData d;
  if (encoder_) {
    const auto enc = encoder_->getData();
    d.position = enc.position;
    d.velocity = enc.velocity;
  }
  d.effort = current_effort_.load(std::memory_order_relaxed);
  d.target_velocity = target_velocity_.load(std::memory_order_relaxed);
  return d;
}
```

## 3. MotorArray 兼容性

`MotorArray` 通过 `MotorInterface*` 多态调用，无需任何修改：

```cpp
// 现有代码完全兼容
static MotorDrv8874 motor_fl(motor_fl_config, &enc_fl, PIDController(pid_config));
static MotorDrv8874 motor_fr(motor_fr_config, &enc_fr, PIDController(pid_config));
static MotorDrv8874 motor_rl(motor_rl_config, &enc_rl, PIDController(pid_config));
static MotorDrv8874 motor_rr(motor_rr_config, &enc_rr, PIDController(pid_config));

static MotorInterface* motors[] = {&motor_fl, &motor_fr, &motor_rl, &motor_rr};
// MotorArray 不关心具体驱动类型，只调用 MotorInterface 虚函数
```

`DriverGroupConfig`（nSLEEP + nFAULT）保持不变。

## 4. PWM 引脚分配方案

### 4.1 ROSbot XL 原始电机 PWM 引脚

| 电机 | PWM (EN) | IN_A | IN_B |
|------|----------|------|------|
| FL | PF9 (TIM14_CH1) | PD10 | PD11 |
| FR | PF8 (TIM13_CH1) | PG5 | PG6 |
| RL | PF7 (TIM11_CH1) | PG11 | PG12 |
| RR | PF6 (TIM10_CH1) | PE12 | PE13 |

### 4.2 ROSbot PRO DRV8874 引脚方案

DRV8874 需要 2 路 PWM/电机，总共 8 路 PWM。方案如下：

| 电机 | IN1 (PWM) | IN2 (PWM) | 定时器 |
|------|-----------|-----------|--------|
| FL | PF9 (TIM14_CH1) | PF6 (TIM10_CH1) | TIM14 + TIM10 |
| FR | PF8 (TIM13_CH1) | PF7 (TIM11_CH1) | TIM13 + TIM11 |
| RL | PE5 (TIM9_CH1) | PE6 (TIM9_CH2) | TIM9 (双通道) |
| RR | PB14 (TIM12_CH1) | PB15 (TIM12_CH2) | TIM12 (双通道) |

**注意**：PB14/PB15 在 ROSbot XL 中用于 LED Strip SPI，如果保留 LED Strip 则需要重新分配。替代方案：

| 电机 | IN1 (PWM) | IN2 (PWM) | 备注 |
|------|-----------|-----------|------|
| FL | PF9 (TIM14_CH1) | PD12 → 占用 | ⚠️ PD12 是编码器 |
| RR (替代) | PA2 (TIM9_CH1) | PA3 (TIM9_CH2) | 如果 PA2/PA3 可用 |

**最终推荐方案**（保留 LED Strip）：

| 电机 | IN1 | IN2 | 定时器分配 |
|------|-----|-----|-----------|
| FL | PF9 | PF6 | TIM14_CH1 + TIM10_CH1 |
| FR | PF8 | PF7 | TIM13_CH1 + TIM11_CH1 |
| RL | PE5 | PE6 | TIM9_CH1 + TIM9_CH2 |
| RR | PD15 | PD14 | TIM4_CH4 + TIM4_CH3 → ⚠️ 冲突 |

由于编码器占用了 TIM1-TIM4，RR 电机需要寻找替代：

**安全方案**：
| 电机 | IN1 | IN2 | 定时器 |
|------|-----|-----|--------|
| FL | PF9 (TIM14_CH1) | PF6 (TIM10_CH1) | 独立定时器 |
| FR | PF8 (TIM13_CH1) | PF7 (TIM11_CH1) | 独立定时器 |
| RL | PE5 (TIM9_CH1) | PE6 (TIM9_CH2) | 共享 TIM9 |
| RR | PA2 (TIM9_CH1) | PA3 (TIM9_CH2) | ⚠️ TIM9 已用 |

**最终安全方案（使用 TIM8 备用通道）**：

由于 TIM8 仅 CH2N (PB0) 被风扇占用，CH1/CH3/CH4 可能可用：
| 电机 | IN1 | IN2 | 定时器 |
|------|-----|-----|--------|
| FL | PF9 (TIM14_CH1) | PF6 (TIM10_CH1) | 独立 |
| FR | PF8 (TIM13_CH1) | PF7 (TIM11_CH1) | 独立 |
| RL | PE5 (TIM9_CH1) | PE6 (TIM9_CH2) | TIM9 双通道 |
| RR | PA5 (TIM8_CH1N) ⚠️ | 冲突 | 需要重新规划 |

> **结论**：精确的引脚分配需要在 ROSbot PRO 设计文档中统一规划，以避免定时器冲突。详见后续的引脚分配精确文档。

## 5. IPROPI 电流回报（可选功能）

### 5.1 工作原理

DRV8874 的 IPROPI 引脚输出与负载电流成比例的电流：
```
I_IPROPI = I_LOAD / 1200  (典型比例 1:1200)
```

通过外接电阻将电流转换为电压：
```
V_IPROPI = I_IPROPI × R_IPROPI = (I_LOAD / 1200) × R_IPROPI
```

推荐 R_IPROPI = 1.0kΩ：
```
V_IPROPI = I_LOAD × (1000 / 1200) = I_LOAD × 0.833
```

| 电机电流 | IPROPI 输出电压 |
|---------|---------------|
| 0A | 0V |
| 1A | 0.833V |
| 2A | 1.667V |
| 3A | 2.500V |
| 3.96A | 3.3V (ADC 满量程) |

### 5.2 MCU ADC 连接

```
DRV8874 IPROPI ──── R_IPROPI (1kΩ) ──── GND
        │
        └──── MCU ADC 引脚 (PA0-PA7, PB0-PB1, PC0-PC5, PF3-PF10)
```

4 路 IPROPI 需要 4 路 ADC 输入，建议使用 ADC3 通道：
- PF3 (ADC3_CH9) → FL 电机电流
- PF4 (ADC3_CH14) → FR 电机电流
- PF5 (ADC3_CH15) → RL 电机电流
- PF10 (ADC3_CH8) → RR 电机电流

### 5.3 电流回报用途

1. **堵转检测**：电流突然升高 → 自动断电保护
2. **力矩控制**：通过电流闭环实现精确力矩输出
3. **效率优化**：空载时降低 PWM 以节省电能
4. **ROS 数据发布**：通过 `effort` 字段报告实际电机力矩

### 6.2 PID 调参建议

DRV8874 的响应特性可能与 DRV8848/MAX22205 不同，需要重新调参：

```cpp
// 初始 PID 参数（从 ROSbot XL 继承，可能需要微调）
inline constexpr PIDConfig pid_config = {
    .kp = 0.15f,    // 比例增益
    .ki = 0.55f,    // 积分增益
    .kd = 0.007f,   // 微分增益
    .min_output = -1.0f,
    .max_output = 1.0f,
};
```

调参步骤：
1. 先设 Ki=0, Kd=0，仅调 Kp 直到响应快速但不振荡
2. 逐步增加 Ki 消除稳态误差
3. 添加少量 Kd 抑制超调
4. 使用 `_motors/feedback` topic 观察实际速度跟踪效果
